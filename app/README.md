# Vibecode Web App

A showcase landing page for [Vibecode](https://www.vibecodeapp.com) — the first mobile app that builds mobile apps.

## Features

- Modern, responsive landing page
- Interactive app builder demo with live phone preview
- Preset templates for fitness, recipe, meditation, and budget apps

## Getting Started

```bash
cd app
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run preview` | Preview production build |

## Tech Stack

- React 19
- TypeScript
- Vite 8
